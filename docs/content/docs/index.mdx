title: Overview
description: Keep Windows games and apps in borderless layouts
---

**Borderless** is a Windows desktop app that keeps games and other windows in borderless (and related) layouts. Match by window title and/or executable, then re-apply styles while Borderless is running.

Useful when a title already runs borderless, fights chrome, or needs extra input/audio rules.
